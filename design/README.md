# Макети мобільного застосунку

Екрани, намальовані з Pavlo 06–07.09.2026 через петлю «намалюй стилусом → я читаю
штрихи з бази артефакту». Тут лежить результат, з якого збирається публічна сторінка.

    screens/*.html    один екран = один файл, 412 × 915, без обгорток
    demo.html         зібрана сторінка (генерується, у git для зручності діффа)

Зібрати:

    uv run python -m church_assistant.scripts.build_demo_page

Розгорнута на **https://cma.rechurch.org.ua/demo** — статикою через Caddy,
повз FastAPI, щоб показувати людям без акаунта. Оновлення вмісту не потребує
перезавантаження Caddy: `handle_path /demo*` уже стоїть у `Caddyfile`.

## ⚠️ Дані тут вигадані, і це правило

Макети малювалися на **справжньому корпусі** — інакше судити про верстку немає
сенсу. Але в git і на публічний URL іде тільки знеособлене: імена, назви тем і
тексти замінені. Якщо переробляєш екран на реальних даних — знеособ перед тим,
як класти сюди. `build_demo_page` має список прізвищ і відмовиться збирати, якщо
побачить їх, але він знає лише те, що йому сказали: це страховка, не політика.

## Що ці екрани вже вирішили

- **Дуга великого пальця.** Пошук унизу, порядок панелі `Головна · Запис ·
  Зустрічі · Пошук` (найчастіше — під правим пальцем), таймкоди праворуч.
  Плей/пауза й «затвердити» — навпаки, подалі: дальній бік це захисна відстань.
- **Пошук, а не чат.** Синтезу немає (виміряно: `docs/handoff_brief.md`,
  «Виміряно: скільки коштує відмова від синтезу»), тож інтерфейс-діалог обіцяв
  би те, чого продукт не робить.
- **Хто що заповнює.** Адмін відкриває зустріч і призначає ведучого; порядок
  денний, кворум і присутніх вносить **ведучий** — це те саме правило, що в
  шапці `018_meeting_protocols.sql`.

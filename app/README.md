# CMA — мобільний застосунок (Flutter)

Екрани з `design/screens/*.html`, перенесені в Flutter 23.10.2026, плюс два нові
після зустрічі з партнером: підпис протоколу біометрією і «Стан справ».
Поки що все на вигаданих даних (`lib/mock_data.dart`) — так само, як і макети:
жодного справжнього імені чи зустрічі тут не має бути.

    lib/main.dart            чотири вкладки: Головна · Запис · Зустрічі · Пошук
    lib/theme.dart           кольори й шрифт (Onest) з макетів, в одному місці
    lib/widgets.dart         картка, ярлик розділу, пігулка статусу, таймкод
    lib/screens/             по файлу на екран; sign_sheet.dart — підпис через local_auth
    android/                 MainActivity = FlutterFragmentActivity (потрібно для біометрії)

## Запустити

    brew install --cask flutter            # один раз
    cd app && flutter pub get
    flutter run                            # на підключеному телефоні або емуляторі
    ./build_apk.sh                         # release → ~/Documents/ReChurch/CMA_app/cma-app-<version>.apk
    ./build_apk.sh http://10.0.2.2:8010    # …-dev.apk проти локального сервера

Версія береться з `pubspec.yaml` (`version: 0.1.0+1`): підніміть її там перед
збіркою, і файл назветься сам. Зараз 0.1.x — етап входу; 0.2 — запрошення й ключ
пристрою; 0.3 — читання даних.

Телефон: увімкнути «Налагодження через USB», підключити кабелем, `flutter devices`
має його показати. Емулятор: `~/Library/Android/sdk/emulator/emulator -avd Medium_Phone_API_35`.

## Вхід (крок 1 підключення до сервера, 23.10.2026)

До входу працює лише вкладка «Головна»: створити церкву або увійти за кодом із
пошти. Церква, створена із застосунку, чекає схвалення власника в панелі
`/platform`; до того застосунок показує «Запит розглядається». Токен живе в
захищеному сховищі телефона рік; на сервері це рядок `web_sessions` з
`client = 'app'`, тож його видно й можна відкликати на сторінці сесій.

    # сервер локально (порт 8010, база cma-dev-postgres на 5434)
    source ~/.claude/jobs/<job>/tmp/dev.env && uv run uvicorn church_assistant.web.main:app --port 8010
    # застосунок на емуляторі → цей Mac
    flutter run --dart-define=CMA_API=http://10.0.2.2:8010
    # показати вигадані дані на екранах (для перегляду дизайну)
    flutter run --dart-define=CMA_MOCK=true

Без SMTP на сервері код друкується в його журнал (`[api] code for …`).

## Що ще не підключено

- Читання даних: лічильники, зустрічі, протокол, стенограма ще не йдуть з API (крок 3); після входу екрани порожні.
- Запрошення членів ради адміністратором (крок 2); картка на першому екрані поки сіра.
- Запис у фоні з надсиланням 10-хвилинними шматками (`screens/record.dart` зараз лише рахує час).
- Підпис: біометрія працює, але підпис ще не ключем пристрою і нікуди не надсилається.
- «Стан справ»: таблиці задач і підписів у базі (міграції) ще не написані.
